# SkillNexa 2.0

## Folder structure

```text
SkillNexa/
├── server.js
├── students.json
├── package.json
├── package-lock.json   # generated by npm install
├── .env
├── .env.example
├── .gitignore
└── public/
    ├── index.html
    ├── css/
    │   └── styles.css
    └── js/
        ├── app.js
        ├── api.js
        ├── data.js
        ├── courses.js
        └── voice.js
```

## Run

1. Copy `.env.example` to `.env`.
2. Put your Gemini API key in `GEMINI_API_KEY`.
3. Open terminal in the SkillNexa folder.
4. Run `npm install`.
5. Run `npm start`.
6. Open `http://localhost:3000`.

## Main rules implemented

- Full Name is saved at registration and reused on the completion certificate.
- Courses are filtered by the student's branch.
- First 2 levels of every selected course are unlocked automatically.
- From level 3 onward, levels unlock sequentially after the previous level is completed.
- Daily Tests and Assignments award Points, not Coins.
- Points determine the overall SkillNexa level.
- Course levels are Basics → Intermediate → Advanced → Pro.
- Each lesson contains step-by-step topics, AI help, YouTube search resources and speaker support.
- AI has no artificial question-count limit.
- Current-information questions attempt live lookup before AI generation.
- Certificate appears after all 5 course levels are completed and can be printed/saved as PDF from the browser.
